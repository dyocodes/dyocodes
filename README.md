---

## Hostlinku Open-Source Developer Ecosystem

| Repository | Purpose | Protocols / Stack |
|---|---|---|
| [**`hostlinku-api-examples`**](https://github.com/dyocodes/hostlinku-api-examples) | Runnable **curl**, **Node.js**, and **Python** examples + official OpenAI/Anthropic SDK scripts with SSE streaming | Chat Completions, Messages, Responses |
| [**`hostlinku-claude-code-setup`**](https://github.com/dyocodes/hostlinku-claude-code-setup) | Drop-in configs & connection verifier for **Claude Code** (CLI, VS Code, JetBrains) with prompt caching & 1M context auto-compact | Anthropic Messages (`count_tokens` + SSE) |
| [**`hostlinku-ide-setup`**](https://github.com/dyocodes/hostlinku-ide-setup) | Ready-to-use templates & verifier for **Cursor**, **Cline / Roo Code**, **Zed**, **Codex CLI**, **OpenCode**, and **Continue** | OpenAI Compatible, Responses, Messages |
| [**`hostlinku-cost-calculator`**](https://github.com/dyocodes/hostlinku-cost-calculator) | Live **USD** token cost calculator (web UI + zero-dependency Node.js CLI) driven by `/api/public/models` | Node.js CLI, HTML/JS, Tiered Pricing |
| [**`hostlinku-gateway-benchmark`**](https://github.com/dyocodes/hostlinku-gateway-benchmark) | Reproducible **TTFT**, `p50`/`p95` latency, and USD cost benchmark CLI | Node.js & Python stdlib, SSE Streaming |
| [**`hostlinku-openapi`**](https://github.com/dyocodes/hostlinku-openapi) | **OpenAPI 3.1** specification and **Postman v2.1** collection across all gateway endpoints | OpenAPI 3.1, Postman Collection |
